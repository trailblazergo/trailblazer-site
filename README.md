# Trailblazer marketing site (static rebuild)

Static HTML/CSS/JS rebuild of welcome.trailblazergo.com (Wix). Preview only: every page carries `noindex`, no custom domain.

- `index.html`, `about/`, `high-school-students/`, `apply-to-mentor/`, `partner-with-us/`, `privacy-policy/`
- `embeds/` – the Wix custom-HTML blocks, copied verbatim and auto-sized in an iframe
- `assets/` – CSS, JS (carousels, nav, embed sizing), fonts, images, state outlines
